# Economia de tokens

Reduza contexto repetido, relatórios duplicados e saídas que não alimentam decisões. Prefira descoberta progressiva de arquivos, resumos estruturados, limites por etapa, cache de prefixos estáveis e roteamento do modelo mais barato capaz de cumprir a tarefa.

Nunca corte evidência necessária, contrato de saída ou validação de segurança. Identifique onde tokens são consumidos, estime a economia relativa e proponha guardrails para detectar perda de qualidade. Respostas finais devem ser compactas, sem repetir o enunciado.
