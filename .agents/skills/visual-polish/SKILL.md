# Refinamento visual

Construa uma linguagem visual coerente com poucos tokens de design: escala tipográfica, espaçamento, raios, superfícies, bordas, elevação e cores semânticas. Use contraste e densidade para sinalizar prioridade, não excesso de brilho.

Evite gradientes gratuitos, glassmorphism ilegível, animações constantes e dezenas de cores. Garanta que componentes tenham estados hover, focus-visible, disabled, loading e error. O resultado deve parecer deliberado em desktop e mobile e continuar legível em telas pequenas.
